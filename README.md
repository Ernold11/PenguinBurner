# Overlay notes — preview site

This branch is **not source code**. It is an orphan branch holding a small
static site with working notes about reworking the PenguinBurner in-game
overlay, published through GitHub Pages so the pages can be linked and read.

- `index.html` — landing page
- `strategy.html` — what the overlay draws today and what to aim at
- `build-order.html` — MangoHud parity matrix and the milestone plan
- `fitting-room.html` — interactive mockup of the proposed HUD

Nothing here is implemented, and nothing here has been validated on hardware.
The branch shares no history with `main` and is never intended to merge.
