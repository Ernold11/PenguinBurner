Interactive. Switch renderer, detail level, corner, size and scene, and watch what changes. The pixel mode draws with a real 5×7 glyph table at the layer’s own spacing, so nothing there is a promise the code cannot keep.

Why this exists: the overlay works and looks like 2004 — one line of capital pixel text on an opaque black bar, welded to the top-right corner. These notes work out what to do about that, in what order, and what each step risks.

Status: nothing here is implemented. No hardware validation has been done for anything in the plan — the machine these were written on has no NVIDIA GPU and no daemon.
