What each mode costs

The honest split

Pixel · M1–M3 · no new Vulkan objects

Everything except transparency

  • Any corner, any number of rows — rectangles do not care where they land.
  • Lowercase and punctuation from a wider glyph table.
  • Colour per value. The draw call already takes a colour; only the white was hard-coded.
  • The frametime graph — a bar per sample is a rect per sample.
  • Solid backing box only, and glyph edges stay square at every size.
Pipeline · M5 · the one risky change

The part that needs blending

  • Translucency — the game stays visible through the panel.
  • Real type, antialiased, sharp at 4K instead of scaled pixels.
  • Rounded corners and a hairline border, which need alpha to not look cut out.
  • Gradients and a filled graph rather than flat bars.
  • Costs a pipeline, two shaders and a font atlas in the present path of every wrapped game — behind a switch, with the pixel path as the fallback.

The asset

The glyph set this needs

Drafted for the mockup and directly reusable: 5×7 cells, uppercase, lowercase, digits and the punctuation the readout uses. The layer ships 45 glyphs today; this is the table that replaces it.

Generated by the same routine that draws the HUD above, so nothing here is a promise the renderer cannot keep.

What this is not: a screenshot. It is the layout and the glyph rules rendered in a browser, on a scene painted to be awkward on purpose. Colours and thresholds will need one pass on real hardware before they are final — bright sky over a light HUD is exactly the case a mockup flatters.
